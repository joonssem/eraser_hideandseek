학교 교실 수업 및 학급 단합 활동에 최적화된 **단일 파일(Single-File) 독립 실행형 3D 웹 멀티플레이어 숨바꼭질 게임**입니다.

## 🎮 게임 룰 및 특징

### 1. 역할
- **지우개 요정 (도망자)**: 교실 사물(책상, 칠판, 바닥 등)을 스포이드로 찍어 몸에 색칠하고 위장합니다. 실제 지우개처럼 눕거나 서서 숨을 수 있습니다.
- **연필 술래 (추적자)**: 숨는 시간(60초) 동안 필통 속 미니게임을 즐기며 대기한 뒤, 찾는 시간(120초) 동안 교실을 수색해 조준점으로 지우개를 검거합니다.
- **선생님 (호스트/관전)**: 전자칠판용 TV 전체 조망 모드, 학생 일괄 "얼음!(Freeze)" 통제, 라운드 시간 조절, 정전 기믹을 제공합니다.

### 2. 4가지 내장 맵
1. **교실**: 책상, 칠판, 사물함, 창가
2. **과학실**: 실험대, 시약병, 플라스크, 현미경
3. **급식실**: 배식대, 긴 식탁, 컨베이어 벨트 식판
4. **도서관**: 대형 서가, 열람실, 실시간 이동 북카트
> 💡 *차기 신규 맵(미술실, 체육관, 음악실 등 5종) 상세 기획안은 [docs/03_new_map_ideas.md](./docs/03_new_map_ideas.md) 문서를 참고하세요.*

## 🚀 GitHub Pages 배포 방법 (초간단 1분 설정)

1. **GitHub 저장소 연결 및 푸시**:
   ```bash
   git remote add origin https://github.com/joonssem/eraser_hideandseek.git
   git branch -M main
   git push -u origin main
   ```
2. **GitHub Pages 활성화**:
   - 저장소 상단 **Settings** 클릭
   - 왼쪽 메뉴에서 **Pages** 클릭
   - **Build and deployment** > **Source**에서 `Deploy from a branch` 선택
   - **Branch**를 `main` 및 `/ (root)`로 선택 후 **Save** 버튼 클릭
3. **접속**:
   - 배포 후 접속 주소: [https://joonssem.github.io/eraser_hideandseek/](https://joonssem.github.io/eraser_hideandseek/)

## 🔧 주요 안정화 및 신규 기능 패치 내역

> **현재 상태:** v2.3.0이 배포 구현입니다. 과거 초안인 scripts/77_apply_infection_mode.py는 현재 코드에 실행하지 않습니다.

### 🧟 v2.3.0 후반 술래 증식 모드
- **학급 실전 균형 반영**: 20~21명 경기에서 최초 술래 4~5명을 유지하고, 찾기 시작 60초 뒤부터 감염을 활성화합니다.
- **탈락 대신 역할 전환**: 활성화 이후 잡힌 지우개는 5초 대기 후 빨간 연필 술래로 변신하여 수색에 합류합니다.
- **기본 모드 보존**: 방 설정에서 선택하는 옵션이며 기본값은 꺼짐입니다.
- **공정한 승패 집계**: 감염되어 술래가 된 학생도 최초 지우개 명단에 남아 전원 검거와 생존자 통계에 정확히 반영됩니다.


### 🎮 v2.2.1 모바일 이동 조작 핫픽스
- **왼쪽 이동 전용 공간 확보**: 수동 도발·포즈 버튼을 오른쪽 조작 영역으로 옮겨 부동 조이스틱의 터치 시작을 막지 않도록 수정.
- **입력 상태 자가 복구**: 조이스틱을 누른 채 색칠 모드로 전환하거나 '얼음!'이 실행될 때 남을 수 있는 포인터 ID와 이동값을 즉시 초기화.
- **'얼음!' 상태 안내**: 이동 제한 중 왼쪽 화면을 누르면 고장이 아닌 교사 제어 상태임을 토스트로 안내.

### 🌟 v2.1.0 신규 기능 업데이트
1. **술래 접근 무음 비주얼 경고 (사운드 혼선 방지)**:
   - 교실 소음 및 옆자리 친구 스포일러를 방지하기 위해 사운드 대신 **화면 테두리가 붉게 깜빡이는 비주얼 경고(Danger Vignette)** 시스템 탑재.
   - 술래가 가까워질수록 테두리 깜빡임이 빨라져 화면을 돌리지 않아도 직감적인 스릴 제공.
2. **탈락 학생(유령) '지우개 가루 청소 퀘스트'**:
   - 일찍 잡힌 학생이 떠들거나 스포일러하지 않도록, 맵 곳곳의 반짝이는 지우개 가루를 수집하는 비행 미니 퀘스트 제공.
3. **Firebase 1GB 무료 용량 보호를 위한 '방 자동 청소 (TTL)'**:
   - 2시간 이상 지난 방 또는 참가자 전원 퇴장 방을 Firebase에서 자동 삭제하여 장기 운영 시에도 100% 무료 유지.
4. **크롬북·웨일북 전용 '온스크린 스포이드 (Q)' 버튼**:
   - 마우스 우클릭이 어려운 학교 노트북 트랙패드 환경을 고려하여 화면 클릭 및 `Q` 단축키 지원.
5. **다채로운 학급 칭찬 뱃지 (MVP Awards)**:
   - 라운드 종료 시 카멜레온 상(보호색), 끈기왕 상(위기탈출), 청소 요정 상(학급미화), 매의 눈 상(최고 술래) 표창 연출.

### 🎵 v2.2.0 '메챠 카멜레온' 1단계 업데이트 (지우개 삑삑이 & 도발 시스템)
- **30초 주기 자동 삑삑이 (Auto-Whistle)**: 숨는 시간이 끝나고 찾는 시간 동안 30초마다 생존한 모든 지우개에서 귀여운 삑삑 소리(`sfxSqueak`)와 별가루 파티클 분출. 술래에게는 거리별 입체 음향 및 방향 힌트 제공!
- **수동 도발 버튼 탑재 (`[🎵 삑!]` & `T`)**: 가만히 숨어있기 심심할 때 술래를 유인하고 놀리는 도발 기능. 술래 근처 도발 성공 시 보너스 점수!
- **학급 MVP 칭찬 뱃지 '대담한 삑삑이상' 추가**: 술래 주변에서 아슬아슬하게 도발을 성공시킨 학생 표창.

### 🎯 v2.1.2 긴급 핫픽스 (술래 연필 모바일 탭 발사 & 1/4 화면 확대 원천 박멸)
- **모바일 화면 직접 탭으로 연필 즉시 발사 (Tap-to-Shoot)**: 우측 하단 버튼을 찾지 않아도, 교실 화면 속 지우개를 손가락으로 톡 터치하면 그 자리에 즉시 연필을 콕 쏘는 직관적인 터치 슈팅 탑재.
- **비상 화면 맞춤 버튼 위치 혁신 (Smart Viewport Tracking)**: 화면 좌상단(`left: 14px; top: 14px;`) 배치 및 시각 뷰포트 오프셋 실시간 추적으로 1/4 확대 시에도 무조건 화면에 노출.
- **매 프레임(60fps) 0ms 즉시 자가 치유(Self-Healing)**: 브라우저가 화면을 키우려는 순간 0.016초 만에 1.0으로 강제 스냅백 복원.
- **연필 쿨다운 단축 (0.8초) 및 쿨다운 알림 토스트**: 먹통 오해 완전 해소.

### 🚨 v2.1.1 긴급 핫픽스 (술래 화면 확대 및 방향키 먹통 완벽 해결)
