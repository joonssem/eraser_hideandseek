# 메챠 카멜레온(Meccha Chameleon) 조사 인사이트 및 타이틀 화면 디자인 분석

## 1. 개요 및 목적
- **문서 목적**: '교실 대소동: 사라진 지우개 찾기'의 핵심 벤치마킹 대상인 글로벌 히트작 **《메챠 카멜레온(MECCHA CHAMELEON / めちゃカメレオン)》**의 웹 조사 결과를 체계적으로 정리하고, 특히 **처음 화면(타이틀 및 메인 메뉴)의 시각 디자인·UX 구조**를 분석하여 본 프로젝트의 UI/UX 개선 인사이트를 도출합니다.
- **작성일**: 2026. 09. 22
- **참고 대상 게임**: 《MECCHA CHAMELEON》 (개발: Lemorion_1224 & Haganeiro / 2026. 06. 10 출시)

## 2. 메챠 카멜레온 게임 현황 및 핵심 메커니즘

### 2.1 게임 개요
- **개발/배급**: 일본 2인 인디 개발팀 (Lemorion_1224 - 기획·아트 / Haganeiro - 시스템 프로그래밍)
- **엔진/플랫폼**: 언리얼 엔진 5(UE5) 기반, PC(Steam) 및 닌텐도 스위치 2(2026.09) 발매
- **성과**: 출시 2개월 만에 2,000만 장 판매 돌파, Steam 동시 접속자 수 34만 명 기록, 2026 일본 게임 대상 Movement Award 수상
- **장르 특성**: 캐주얼 파티 잠입 액션 / '프렌드슬롭(Friendslop)' 및 스트리머 친화형 합방 게임

### 2.2 핵심 게임플레이 구조
1. **페인팅 위장 (Camouflage)**:
   - 플레이어(카멜레온)는 무늬와 색이 없는 순백색 인간형/물방울/큐브 캐릭터로 시작합니다.
   - 스포이트(Eyedropper) 및 컬러 피커를 이용해 주변 환경(벽, 바닥, 사물)의 색상과 질감을 캐릭터 신체에 직접 칠합니다.
2. **포징 및 스케일 변환 (Posing & Scaling)**:
   - 웅크리기, 눕기, 기울이기 등 다양한 자세를 취해 사물 형태와 일치시킵니다.
   - 크기 변환(작게/보통/크게) 및 분신 생성 기능을 활용합니다.
3. **술래(Hunter)의 추적**:
   - 제한 시간 내 의심스러운 배경이나 부자연스러운 색채 차이를 관찰하여 은신한 플레이어를 찾아냅니다.

## 3. 처음 화면 (타이틀 & 메인 로비) 디자인 분석

### 3.1 화면 진입 시퀀스 (Entry Sequence)
1. **타이틀 대기 화면 (Press Start / Press Any Key)**
   - 게임 구동 시 가장 먼저 마주하는 화면입니다.
   - 복잡한 UI 창 대신 강렬한 비주얼 연출과 함께 "Press Any Key" 또는 "Press Start" 안내 문구가 깜빡입니다.
   - 키 입력 시 스팀/에픽 온라인 서비스의 사용자 인증 및 네트워크 토큰 검증 후 메인 메뉴가 활성화됩니다.
2. **메인 메뉴 화면 (Main Hub)**
   - 멀티플레이 파티 게임 특성에 맞추어 불필요한 서브 뎁스를 배제하고, 즉시 매치 진입이 가능한 원클릭 레이아웃을 채택했습니다.

### 3.2 비주얼 테마 및 배경 연출
- **게임 규칙의 시각적 직관화 (Show, Don't Tell)**:
  - 타이틀 화면의 중앙 또는 우측에 **새하얀 기본 캐릭터 모델**이 서 있습니다.
  - 특히 캐릭터의 신체 일부가 뒷배경(벽돌 벽면, 타일 바닥 등)의 패턴과 색상에 맞춰 **반쯤 페인팅되어 배경 속에 녹아들어 있는 모습**으로 연출되어 있습니다.
  - 유저는 텍스트 튜토리얼을 읽기 전에 이미 *“몸에 색을 칠해 배경에 동화되는 게임”*임을 시각적으로 한눈에 학습하게 됩니다.
- **배경 씬 (3D Background)**:
  - 과도하고 무거운 시네마틱 대신, 깔끔한 조명이 비추는 3D 쇼룸 공간이나 게임의 대표 맵(숨바꼭질 저택 벽면)을 단정한 배경으로 사용합니다.

### 3.3 로고 및 타이포그래피 (Branding)
- **로고 스타일**:
  - 카멜레온의 피부색 변화 특성을 모티브로 한 **알록달록한 다채로운 색상(Multicolored / 그라데이션)**이 적용된 볼드(Bold) 폰트입니다.
  - 가볍고 유쾌한 인디 파티 게임의 무드를 살린 팝(Pop)한 디자인입니다.
- **위치**: 화면 상단 중앙 또는 좌측 상단에 큼직하게 배치되어 브랜드 아이덴티티를 확립합니다.

### 3.4 메인 메뉴 버튼 구조 및 기능
| 버튼/메뉴명 | 기능 설명 |
| :--- | :--- |
| **Play / Join Lobby** | 공개 서버 목록(Public Lobbies) 브라우저를 열어 빈 방을 검색하거나 빠른 참가 |
| **Host / Create Room** | 방장으로서 맵(숨바꼭질 저택, 백룸, 펭귄 호텔 등), 게임 모드(일반, 감염, 더블, 리버스 치킨 레이스), 공개/비공개(비번/초대) 설정 |
| **Settings** | 그래픽(해상도, 전체화면/창모드), 조작키(Keybinds), 오디오 볼륨, 언어(한국어, 영어, 일본어 등) |
| **Steam Workshop** | 유저 커뮤니티가 제작한 창작마당 커스텀 맵 브라우징 및 구독 |
| **Quit / Exit** | 게임 종료 |
| **버전 및 상태 표시** | 화면 모서리(우측/좌측 하단)에 현재 빌드 버전(Version info) 및 네트워크 핑 상태 작게 표시 |

## 4. '지우개 숨바꼭질' 프로젝트 적용 인사이트

본 프로젝트(교실 대소동: 사라진 지우개 찾기)는 웹 브라우저 기반의 단일 파일(Single-file) 독립 실행형 구조를 가지므로, 메챠 카멜레온의 디자인 철학 중 다음 요소를 효과적으로 흡수할 수 있습니다.

### 4.1 타이틀 화면 비주얼 개선: '위장 지우개' 3D 프리뷰 연출
- **현재 상황**:
  - 레트로 칠판 배경과 텍스트 버튼 위주의 2D UI로 구성되어 있어, 처음 접속한 학생이 "어떻게 플레이하는 게임인지" 즉시 체감하기 어렵습니다.
- **벤치마킹 적용안**:
  - 타이틀 화면 뒤편 WebGL 캔버스에 **'책상 나무결 텍스처'**를 배경으로 두고, 그 위에 놓인 **새하얀 지우개 캐릭터의 절반이 책상 나무결 색상으로 칠해져 반쯤 투명인간처럼 동화되어 있는 3D 모델**을 회전/배치합니다.
  - 별도의 설명 없이도 "아! 지우개에 책상 색을 칠해서 숨는 게임이구나!"를 직관적으로 각인시킬 수 있습니다.

### 4.2 초간결 진입 플로우 (Zero-Barrier Flow) 유지 및 강화
- 메챠 카멜레온이 2클릭 내에 매칭에 진입하도록 만든 것처럼, 지우개 숨바꼭질의 가장 큰 무기인 **"교사 1클릭 방 생성 + 전자칠판 대형 QR 코드 표시 + 학생 카메라 스캔 즉시 닉네임 입력 후 입장"** 구조의 단순성을 타이틀 화면의 최우선 가치로 유지해야 합니다.
- 불필요한 설정 창을 띄우지 않고, 화면 진입 시 핵심 버튼 2개(`선생님 방 만들기(TV)`, `학생 참여하기`)를 명확히 대비시킵니다.

### 4.3 색상 대비를 활용한 시각적 재미 (무채색 vs 비비드)
- 메챠 카멜레온의 시각적 매력은 **'새하얀 무채색 캐릭터'**와 **'다채로운 원색/주변 환경 텍스처'**의 강렬한 대비에서 나옵니다.
- 지우개 숨바꼭질에서도 기본 순백색 지우개와 대비되는 교실 사물(빨간 연필, 파란 필통, 노란 자, 초록 칠판)의 비비드한 컬러 팔레트를 타이틀 타이포그래피와 UI 버튼에 적극 활용합니다.

### 4.4 신규 맵/모드 선택 UI의 카드화
- 메챠 카멜레온이 방 생성 시 맵과 모드를 직관적으로 선택하게 하듯, 향후 추가될 초등학교 특화 5종 맵(미술실, 체육관, 음악실, 보건실, 돌봄교실)과 3종 모드(베이직, 감염, 더블)를 타이틀/방생성 화면에서 아기자기한 **학용품 스티커/카드 형태**로 선택할 수 있도록 UI를 확장합니다.
