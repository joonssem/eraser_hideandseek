# 게임 모드 현장 시험표

## 시험 목적

20~21명 학급에서 베이직·감염 모드의 승률과 진행 속도를 비교해 술래와 지우개의 목표 승률을 각각 40~60%로 맞춘다.

## 고정 조건

- 숨는 시간: 60초
- 찾는 시간: 180초
- 베이직 자동 술래: 20명 5명, 21명 6명
- 감염 자동 술래: 20명 4명, 21명 5명
- 감염 변신 대기: 5초
- 같은 시험 묶음에서는 맵과 참여 인원을 가능한 한 유지한다.

## 권장 시험 순서

1. 감염 모드 · 즉시 시작을 3회 진행한다.
2. 술래가 3회 모두 승리하면 감염 시작을 30초 후로 늦춘다.
3. 지우개가 3회 모두 승리하면 즉시 감염을 유지하고 최초 술래를 한 명 늘려 비교한다.
4. 어느 한쪽도 3회 모두 승리하지 않으면 같은 설정으로 총 5회까지 진행한다.

## 판정 기준

- 술래 2~3승 / 5회: 목표 범위, 설정 유지
- 술래 4~5승 / 5회: 감염 시작을 30초 또는 60초로 늦춤
- 술래 0~1승 / 5회: 감염 시작을 앞당기거나 최초 술래를 한 명 늘림
- 평균 전원 검거가 120초 이전: 술래가 지나치게 강함
- 대부분 마지막 30초까지 생존자가 있음: 긴장감이 유지되는 적정 흐름
- 120초 시점에 7명 이상 생존: 술래가 여전히 크게 불리함

## 완료 조건

- 실제 iPad Safari에서 빨간 연필 전환 및 검거가 정상 동작한다.
- 감염자가 포함되어도 전원 검거 즉시 결과 화면으로 이동한다.
- 기록 화면의 최초 지우개 수, 감염 수, 생존자 수가 실제 경기와 일치한다.
- 5회 기준 어느 한 팀의 승률도 80%를 넘지 않는다.
