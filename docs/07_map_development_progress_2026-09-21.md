## 실제 학생 현장 테스트 계획

- 상태: **예정 — 실제 학생들과 수업 중 단계적으로 진행**
- 자동화와 브라우저 기본 검증은 통과했지만, 현장 테스트가 끝나기 전에는 온라인 다중 접속과 모바일 조작을 최종 완료로 판정하지 않는다.
- 기록 기준은 [게임 모드 현장 시험표](./02_game_mode_field_test.md)를 사용한다.
- 회차별로 날짜, 참여 인원, 사용 기기, 선택 맵, 게임 모드, 승패, 생존자 수, 접속 이탈, 조작 문제와 특이사항을 기록한다.
- 신규 맵별로 스폰 안전성, 이동 정체, 시야 차폐, 무적 지점, 프레임 저하와 기믹 잔존 여부를 관찰한다.
- 문제가 발견되면 재현 조건과 영향 범위를 먼저 기록한 뒤 별도 수정 단계로 전환한다.
