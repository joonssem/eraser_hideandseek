## 단계별 기록

### 1단계 — 미술실 기준 모듈 교정 및 통합 명세

- `maps/art_room.js`의 벽 높이 변경을 `setWallHeight(34)` 계약으로 정리
- 건조대 12단 및 프레임·선반별 충돌체 구성, 통짜 선반 AABB 제거
- 구현되지 않은 물감 발자국은 플레이어 위치·이동 계약 전까지 보류로 표시
- `docs/05_new_maps_specification.md`의 `MAPS` 객체, `mapIsReady()` module 분기, 활성 맵 기믹 업데이트, `buildActiveMap(mapId)` 및 통합 변경 항목 보완
- Codex 정적 검토 결과: PASS

### 2단계 — 독립 프리뷰 환경

- `maps/preview.html`에서 맵을 배포본과 독립적으로 렌더링
- OrbitControls, 세 카메라 프리셋, 스폰·충돌체 디버그 표시, HUD, 재빌드 UI 제공
- 첫 검증에서 천장·외벽이 내부를 가리던 문제를 발견하여 기본 숨김 및 별도 토글 추가
- Codex가 브라우저에서 기본 쿼터/상공/전면 시야, 토글, 반복 재빌드를 확인
- HUD 불변 확인: 미술실 `34 / 20 / 6 / 73 / 258`
- Codex 판정: PASS

### 3단계 — 체육관

- `maps/gymnasium.js` 구현, 프리뷰 선택 목록에 체육관 연결
- 벽 높이 48, 요정 20, 술래 6, 볼 카트·늑목·뜀틀·매트 등 구성
- 첫 검토에서 프리뷰 맵 전환 시 이전 맵이 아닌 새 맵 cleanup을 부르던 순서 오류를 교정
- 구름판의 미지원 `rx` 옵션 제거. 베이스와 탄성 상판으로 재구성하고, 상판 AABB를 실제 메시 크기와 일치시킴
- 구름판 펄스 머티리얼에 투명도·발광 변화를 추가하고 cleanup에서 전용 머티리얼 해제
- 슈퍼 점프는 플레이어 물리 계약 전까지 보류
- Codex가 미술실↔체육관 전환과 3회 재빌드를 브라우저에서 확인
- 최종 HUD: 체육관 `48 / 20 / 6 / 82 / 96` (구름판 수정 전 초안의 충돌체 80에서 최종 82)
- Codex 판정: PASS

### 4단계 — 음악실

- `maps/music_room.js` 구현, 프리뷰 선택 목록에 음악실 연결
- 피아노 백건 14개·흑건 10개, 실로폰 8색 건반, 보면대 숲 12개, 국악기, 메트로놈 구현
- Web Audio 및 AudioContext 생성 없이 피아노 사운드는 보류, 메트로놈 시각 운동만 활성화
- Codex 검토에서 합창석 AABB와 피아노 벤치 AABB 안쪽에 놓인 요정 스폰을 발견
- 요정 스폰 20개를 y=0 바닥으로 재배치하고, 술래 6개와 함께 XZ 겹침 전수 검사를 AGY가 보고함: 26개 스폰 × 85개 AABB, 0건
- Codex가 실제 음악실 프리뷰에서 스폰 위치, HUD, 3회 재빌드를 확인
- 최종 HUD: 음악실 `35 / 20 / 6 / 85 / 84`
- Codex 판정: PASS
